# Review: ADR 001 Multimodal Latent Clustering Methodology

**Verdict: do not accept this ADR as written.** The clustering produced a usable curatorial taxonomy, but the document overstates empirical validation, silently dropped the original clustering approach, and includes a feature that works against its own problem statement. Status should be `PROPOSED` until Gate 2a.

The repo copy at `Google Arts & Culture/docs/adr_001_latent_clustering_methodology.md` matches the brain file. The earlier Phase 2a self-audit already flagged several of these issues; none of those caveats made it into the ADR.

---

## What holds up

The problem statement is the right one: 801 critiques are not a design system until they are grouped into 8–12 opinionated lineages, and grouping by era or museum partner would be trivial.

The feature recipe is reconstructable enough to rerun. Color uses a real sRGB→CIELAB D65 conversion. The evaluation table exists. Upstream data was left alone. Several clusters are coherent on inspection: Cluster 1’s nearest-centroid works are maps; Cluster 3’s thesis matches maritime panoramas; Cluster 8’s Jekyll plan is a fair botanical-planning anchor.

That is a **curatorial success**. It is not a validated latent-space result.

---

## Blocking issues

### 1. The semantic vector includes the trivial axes the ADR says it is avoiding

Section 2C concatenates `{title} {creator} {medium}` into the TF-IDF corpus. Section 1 says the whole point is to avoid groupings like “17th Century Dutch” and recover trans-historical design lineages.

That feature choice is doing the opposite. From `favorites_clustered.json`:

| Cluster | Smoking gun |
|---|---|
| **2** Bauhaus Functionalism (n=51) | **34 / 51 are Franz Ehrlich (67%)**. Five of six manifest anchors are Ehrlich or his Bauhaus-adjacent drafting circle. |
| **9** Geometric Abstraction (n=77) | 15 works by Lazar Khidekel. |
| **5** Graphic Semiotics (n=150) | Nearest-centroid members include a 2019 digital poster, a children’s carpet, an Ethiopian amulet book, a world map, and a Sol LeWitt wall drawing. |

Cluster 2 is largely an artist archive with a design-school label. That is exactly the naive grouping §1 rejects. Drop `creator` and `medium` (and likely `title`) from the text composite, re-cluster, and check whether the Bauhaus cluster still exists as a spatial/semantic lineage. If it collapses, the name is an artifact of TF-IDF on artist strings.

### 2. The “optimal k=10” claim is not what the table says

Read the K-Means numbers as a function of *k*:

| *k* | Silhouette | Calinski–Harabasz |
|---|---|---|
| 8 | 0.0750 | **29.77** (best CH) |
| 9 | 0.0763 | 28.81 |
| 10 | 0.0790 | 28.40 |
| 11 | 0.0846 | 26.92 |
| 12 | **0.0883** (best sil) | 26.75 |

Silhouette **rises** with *k*. CH **falls** with *k*. Neither metric prefers 10. The selected row is a qualitative judgment (“ideal conceptual granularity”) presented as an empirical optimum.

Worse, **0.079 is weak structure**. Silhouette ranges from −1 to +1; below ~0.25 usually means overlapping blobs, not separable clusters. Calling this “superior cluster separation” and “tighter spherical density” overstates the metric. These are imposed taxonomies, not recovered natural groups. That is acceptable for a playbook — it is not acceptable as written.

The matrix is also incomplete: Ward is missing for *k*=11 and 12, so the head-to-head is truncated at the selected *k*.

### 3. UMAP / HDBSCAN / CLIP were specified, then dropped without an alternatives section

This is an ADR that never records the decision it actually made.

The original plan, the README, and the implementation plan all name UMAP + HDBSCAN (and CLIP/SigLIP or “semantic embeddings”). HDBSCAN was the mechanism for **bridge works** (outliers). K-Means assigns every point; bridges cannot exist.

The ADR evaluates only Ward vs K-Means, then treats K-Means as settled. There is no **Decision**, **Alternatives considered**, or **Consequences** section. For an ADR, that is the missing core: *why this, not that, and what you give up*.

TF-IDF + TruncatedSVD on Gemini critiques is also not “semantic embeddings.” It is bag-of-words LSA on formulaic LLM prose (`employ`, `utilize`, `hierarchy`). That will cluster writing style as much as visual structure.

### 4. Status is `ACCEPTED` before Gate 2a

The implementation plan makes Gate 2a a user checkpoint on the manifest, metrics, and map. Declaring `ACCEPTED` before that review is the same premature-complete pattern as Phase 1. This should be `PROPOSED`.

## Methodology gaps the ADR does not disclose

**Evaluation and production are not the same model.** `test_clustering.py` uses `n_init=20` and includes `symmetry_balance` in the text composite. `generate_phase2a_clustering.py` uses `n_init=30` and omits `symmetry_balance`. The ADR cites `n_init=30`. The silhouette table may not describe the file that was shipped.

**Weights are asserted.** \(w_{color}=1.0\), \(w_{spatial}=0.8\), \(w_{semantic}=1.2\) have no ablation. Semantic is both the largest block (25 dims, z-scored) and the highest weight, so TF-IDF dominates Euclidean K-Means by construction.

**The \(\mathbb{R}^{27}\) spatial vector is not the category list in the ADR.** The listed categories sum to 25 (4+4+3+5+4+4+1). 27 is true only because orientation in the data is six values, not four: `Panoramic (Landscape)`, `Panoramic (Portrait / Vertical Scroll)`, `Landscape`, `Portrait`, `Square`, plus `Unknown` for 11 missing rows. The ADR’s category inventory is wrong.

**Mixed-type Euclidean K-Means.** Color and SVD are z-scored; one-hots are not. Rare one-hots (`claustrophobic` n=1, `low` contrast n=7) sit on a different scale from Lab means. `chromatic_temperature` is also 67% `mixed`, so that one-hot is near-constant. Temperature is double-counted (`chromatic_temperature` + \(\bar{a}^*, \bar{b}^*\)); so is contrast (`contrast_level` + \(\Delta L^*\)).

**“Color science” is five vision-model hexes.** 778 works have 5 swatches; 19 have none and become `#808080`. Palette-mean Lab is not an image statistic. Fine as a cheap proxy; not fine as written.

**“SHA-verified” records no hash.** The telemetry audit report does this properly. The ADR does not.

**The 2D map is PCA, titled as a manifold.** With silhouette 0.079, two principal components will not show crisp islands. The SVG is a presentation artifact, not evidence of separation.

**Cluster 5 (18.7%) and Cluster 7 (18.2%) are 37% of the corpus.** Cluster 5’s name does not describe its nearest members. If those two become playbooks as-is, the precepts will be generic.

**Missing-value policy is implicit.** Empty orientation → `Unknown`; empty framing → `balanced`; empty light → `diffuse`; empty contrast → `medium`; empty temperature → `neutral`. That imputes majority-ish defaults and is not documented.

## Document structure

Against a normal ADR template this file is a lab notebook with a status line, not a decision record.

| Expected | Present |
|---|---|
| Status / Date / Deciders | Yes, but status is premature |
| Context | Yes, and clear |
| Decision | No standalone statement |
| Alternatives considered (UMAP, HDBSCAN, CLIP, embeddings, *k* selection rule) | No |
| Consequences (no bridge works, spherical clusters, playbook granularity) | No |
| Reproducibility (script, sklearn version, seed, exact corpus fields) | Partial; conflicts with the eval script |
| Honest limits of the metrics | No |

The mean-chroma formula \(\bar{C}^* = \sqrt{a^{*2}+b^{*2}}\) is the chroma of a single \((a^*,b^*)\) pair. The code averages per-swatch chroma, then also stores mean \(a^*\) and \(b^*\) separately.

## What to change before Gate 2a can honestly accept this

1. Set status to **PROPOSED**.
2. Remove `creator` / `medium` (and probably `title`) from the TF-IDF composite; re-run *k*=10; report whether Cluster 2 remains a design lineage or an Ehrlich bucket.
3. Add **Alternatives considered**: UMAP+HDBSCAN and real embeddings, with a real reason for rejection — or run them.
4. Rewrite §3 so *k*=10 is a **curatorial choice** under weak separation, not an “optimal” metric winner. State that silhouette 0.079 means overlap.
5. Flag Cluster 5 (and possibly 7) for human split-or-keep at Gate 2a. Do not freeze a catch-all into a `design.md`.
6. Align eval and production scripts; pin `n_init`, corpus fields, `random_state`, sklearn version; put the SHA-256 of `favorites_clustered.json` in the ADR.
7. Label weights as domain judgment, not tuned parameters.
8. Correct the orientation inventory and the mean-chroma formula.

Until (2), (3), and (4) are done, treating this as the locked methodology for Phase 2b catalogue injection will bake artist-name clusters and a 150-item grab-bag into every downstream playbook.
